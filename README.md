# rclone personal OAuth website

This folder contains the public homepage and privacy policy for a private,
single-user rclone OAuth application.

## Intended GitHub Pages URLs

- Homepage: `https://pyendluru.github.io/rclone-oauth-info/`
- Privacy policy: `https://pyendluru.github.io/rclone-oauth-info/privacy.html`

## Publishing

Publish these files from the root of a public GitHub repository named
`rclone-oauth-info`, with GitHub Pages configured to deploy from the default
branch.

Never add the Google OAuth client secret, OAuth tokens, or `rclone.conf` to
this repository.
