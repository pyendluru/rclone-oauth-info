Privacy Policy

This policy explains how the personal rclone OAuth configuration uses Google user data.

Application and audience

rclone is configured here as a private, single-user connection using the open-source rclone command-line program. It is used only by its owner and is not offered to the public. This is not the official privacy policy of the rclone project.

Data accessed

With the owner's authorization, the application may access Google Drive file names, metadata, folder structures, and file contents. Depending on the command the owner chooses, it may create, update, move, or delete files in Google Drive.

How data is used

Google Drive data is used solely to perform file backup, synchronization, copying, and restoration requested by the owner. Google user data is not used for advertising, profiling, analytics, or artificial-intelligence model training.

Storage and security

File transfers occur directly between the owner's device and Google Drive. OAuth credentials and tokens are stored locally in the owner's rclone configuration and are not intentionally transmitted to an application-operated server. The owner is responsible for protecting the device and configuration file.

Sharing and sale

Google user data is not sold, rented, or shared with third parties by the application owner. Processing performed by Google and the rclone software remains subject to their respective terms and policies.

Retention and deletion

The application does not maintain a separate external database of Google user data. Local files and configuration data remain until the owner deletes them. Access may be revoked at any time from the Google Account security settings, and the local rclone configuration may also be removed.

Policy changes

This page will be updated if the application's data practices change. The effective date at the top identifies the latest version.
