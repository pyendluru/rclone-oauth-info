Private utility

rclone

A private, single-user setup used to transfer files between the owner's computers and the owner's Google Drive account.

Purpose

This setup uses the open-source rclone project for personal file backup, synchronization, and restoration. It is not offered as a service to the public and does not provide accounts for other users. This page is for a personal OAuth configuration and is not the official website of the rclone project.

How Google data is used

Access to Google Drive is used only to list, read, create, update, and delete files when the owner runs an rclone command. Transfers occur directly between the owner's device and Google Drive.
